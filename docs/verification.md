# Проверка PublishFlow

Проверено локально 29 сентября 2026 года на Docker Compose с PostgreSQL 17 и RabbitMQ 4.

- Ruff: форматирование и статический анализ прошли.
- mypy: ошибок в 16 модулях приложения нет.
- Pytest: 15 тестов прошли, включая конкурентное редактирование, отправку на
  согласование, гонку планировщика с ручной публикацией и проверку опубликованной версии.
- Импорт: проверены сохранение готовых строк после сбоя, параллельные workers,
  исчерпание пяти попыток и ручной повтор с сохранением причины.
- RabbitMQ: проверены подтверждения, маршрутизация событий и карантин для повреждённого
  JSON, неверных типов ID и неправильной структуры сообщения. Ошибка отправки
  оставляет событие в outbox.
- Откат новой миграции и повторное применение сохранили исторические поля тестовых
  пользователей, статей, версий, истории, заданий, строк импорта и outbox.
- Полный Compose-стенд запущен: API, БД и RabbitMQ прошли healthcheck, три фоновых
  процесса работают. `/health` вернул успешный ответ, процесс API использует UID 10001.

GitHub Actions повторяет статические проверки, тесты, проверку миграции и запуск стенда.
Статус конкретной публикации следует смотреть в Actions соответствующего коммита.

Нагрузочные испытания, HA, восстановление резервной копии и внешний потребитель событий
статей не проверялись. Браузерный интерфейс в проекте отсутствует; проверялся HTTP API.
